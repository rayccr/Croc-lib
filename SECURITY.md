# Security / 安全反馈

Please report vulnerabilities through a private GitHub security advisory in this repository. Include version, Windows version, reproduction steps and sanitized logs. Remove transfer codes, relay passwords, personal paths and file contents. If private reporting is unavailable, open an issue requesting a private contact without publishing vulnerability details.

请优先使用本仓库的私密安全报告，附版本、Windows版本、复现步骤和脱敏日志。日志应去掉口令、中继密码、个人路径和文件内容。若私密报告未启用，可发Issue申请私下联系渠道。

Preview releases have limited validation. Network interruptions, suspend/resume, hostile path races and large-scale workloads require further testing.
